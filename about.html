What this site is, who it is for, and how it was built.

About the project

Atlas Local is a student-built sample travel website created for ITC 2400. The goal of the project is to demonstrate strong HTML5 structure, responsive CSS styling, and complete site navigation across all pages.

Audience

The site is designed for visitors who want a simple way to compare travel styles, browse package options, and request a more personalized plan through a clear contact form.

Photo credits

This version uses real destination photographs from Wikimedia Commons with Creative Commons licenses. The Paris image is from Guillaume Speurt, the Tokyo skyline image is from Luke Ma, and the Rome Colosseum image is from Dietmar Rabich. A full attribution list is included in the project folder.

Technical notes

All HTML files are stored in the root folder, the stylesheet is in the css folder, and site images are placed in the images folder. The site uses semantic HTML5 elements including header, nav, main, section, article, aside, and footer.
